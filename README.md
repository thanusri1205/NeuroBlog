# NeuroBlog

An AI-powered blogging platform that helps users create, manage, and publish blogs with the assistance of Large Language Models (LLMs). The application provides AI-generated content suggestions, making blog writing faster and more efficient.

---

## ✨ Features

- 📝 Create and publish blog posts
- 🤖 AI-assisted blog content generation
- 📚 View and manage published blogs
- 🔍 Search and browse blog posts
- 💻 Responsive and user-friendly interface
- 🗄️ Secure blog storage using PostgreSQL

## 🚀 Getting Started

### Prerequisites

- Python 3.9+
- npm
- PostgreSQL

### Installation

1. Clone the repository

```bash
git clone https://github.com/thanusri1205/neuroblog.git
```

2. Navigate to the project directory

```bash
cd neuroblog
```

3. Install frontend dependencies

```bash
npm install
```

4. Install backend dependencies

```bash
pip install -r requirements.txt
```

5. Configure the PostgreSQL database.

6. Start the backend server

```bash
uvicorn app:app --reload
```

7. Start the frontend

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
